# Shristi Sharma — Portfolio

A personal portfolio website built with plain HTML and CSS.

## Structure

- `index.html` — main page (About, Projects, Contact sections)
- `style.css` — all styles

## Running locally

Just open `index.html` in any browser — no build step needed.

## Deploying

This site can be deployed on GitHub Pages:

1. Go to **Settings → Pages** in this repo
2. Set source to the `main` branch, root folder
3. Save — your site will be live at `https://shrissharma049.github.io/Shristi-Portfolio/`
